# План: Telegram-бот и админка для сайта БАЙКАРС

Статус: этап 1 пройден 25.10.2026. Хостинг Timeweb Optimo (vh460.timeweb.ru, тех. адрес https://co177080.tw1.ru), PHP 8.2 + GD/Imagick/SQLite, Node 22 в ~/node, вебхук @buycars_admin_bot работает, YandexGPT Lite отвечает. Секреты в ~/buycars/config.php (вне public_html). Код сервера в `_server/`.
Этап 2 пройден 25.10.2026: SQLite `~/buycars/data/buycars.sqlite` (cars, photos, users, meta), исходники сайта и фото в `~/buycars/site/`, 10 машин импортированы, `export.php` выдаёт cars.json один в один с текущим.

| 12 | Проданные | Кнопка «Продано»: машина исчезает с сайта, остаётся в архиве |

## Как проходит машина

1. Менеджер шлёт боту альбомы фото и текст с характеристиками (или пересылает пост канала).
2. Вебхук (PHP) складывает фото во временный черновик, скачивает их через Bot API.
3. Текст уходит в YandexGPT Lite, назад приходит JSON с полями. Проверка обязательных полей и дублей.
4. Бот присылает карточку «Всё верно?».
5. «Да»: фото режутся до 800×600 плюс превью, машина пишется в хранилище, ставится флаг пересборки.
6. Cron запускает сборку, сайт обновлён (задержка до минуты). Класс машины (Премиум, Средний, Бюджет) считается по цене, как сейчас.

## Этапы

1. Тест на Timeweb: эхо-бот на PHP-вебхуке, проверка доступа к api.telegram.org и YandexGPT, запуск Node по cron.
2. Хранилище и перенос текущих 10 машин из `data/cars.json`.
3. Бот: приём фото и текста, разбор, карточка, дубли, доступы.
4. Админка Mini App: список, правка полей, порядок фото, «Продано», архив.
5. Сайт: убрать блок «Фото салона» под флаг, сборка из хранилища, sitemap, robots.txt, микроразметка AutoDealer.
6. Переезд на домен, вебхук, бэкапы, снос GitHub Pages.

## Что нужно от Вася и салона

- Домен: кто владеет, свободен ли.
- Оплата Timeweb (Optimo) и аккаунт Yandex Cloud с привязанной оплатой.
- Токен бота от @BotFather. Хранится в конфиге на хостинге вне папки сайта, в git не попадает.
- Telegram ID менеджеров.
