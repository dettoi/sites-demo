# Шаблон лендинга автосервиса

Один шаблон на всех клиентов. Клиент = папка `clients/<slug>/` с `client.json` и фото.

## Новый клиент
Полный процесс с агентами описан в `_docs/PIPELINE.md`. Коротко:
0. Снять данные: `node _template/fetch-2gis.mjs <ссылка 2ГИС> <slug>`. Появятся `clients/<slug>/facts-2gis.json` и `photos-2gis/`.
1. Скопировать `clients/damir-avto/client.json` в `clients/<slug>/client.json` и заменить данные.
2. Положить фото в `clients/<slug>/photos-2gis/` (или указать `"photosDir"` в client.json).
3. Поменять акцент в `theme.primary` (цвет бренда клиента). Для светлых акцентов (жёлтый) добавить `"ink": "#16191c"`: цены и логотип станут графитовыми, акцент останется на кнопках и звёздах.
4. Собрать: `node _template/build.mjs <slug>`, результат появится в `clients/<slug>/site/`.
5. Посмотреть: `node _template/serve.mjs <slug>`, затем открыть http://localhost:4321.

## Файлы
- `render.mjs` — разметка всех блоков. Любой блок выключается через `"enabled": false`.
- `styles.css` — стиль B · Асфальт (см. `_docs/DESIGN.md`).
- `build.mjs` — сборка в статический сайт: HTML + CSS + только использованные фото.

## Форма записи
Форма пока ничего не отправляет, а только показывает «Спасибо! Перезвоним в ближайшее время.». Для боевой версии нужно подключить отправку (Telegram-бот).

## Услуги и галерея
- `services.visible` (по умолчанию 8) — сколько позиций показано сразу; остальные раскрываются кнопкой «Показать все услуги (N)». Если позиций не больше `visible`, кнопки нет.
- `gallery.photos` — карусель: на десктопе видно 3 фото, на мобильном 1 со свайпом и точками.
- У отзывов поле `date` не используется.
