# DESIGN.md — B · Асфальт

Нейтральный тёмный стиль для автосервисов. Холодный графит не спорит с фото клиента, один медный акцент отмечает действия. Стиль составлен вручную, без сверки с референсами реальных сайтов.

## Цвет
| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#0f1214` | фон страницы |
| `--surface` | `#161a1d` | карточки, плашки |
| `--surface-2` | `#1e2327` | вторая подложка, заглушки |
| `--line` | `#2a3036` | границы, разделители секций |
| `--text` | `#e7ecef` | основной текст |
| `--muted` | `#96a0a8` | вторичный текст, подписи |
| `--primary` | `#d9773a` | главные кнопки, цены, звёзды |
| `--on-primary` | `#0f1214` | текст на primary |
| `--ok` | `#4fbf6a` | индикатор «открыто» |

Только один акцент. Под клиента меняется `--primary`, остальное остаётся.

## Типографика
- Семейство: **Manrope** (Google Fonts, есть кириллица), 400 / 500 / 700 / 800.
- Заголовки: 800, межбуквенный −0.02em, обычный регистр.
- H1 `clamp(34px, 6vw, 64px)`, H2 `clamp(26px, 3.6vw, 40px)`, H3 20px, основной текст 16px / 1.55, лид 19px, подписи 14px.

## Отступы
- Сетка 4/8px. Ширина контента 1160px, боковое поле 20px.
- Секции: 72px по вертикали (на мобильном 48px), граница `--line` сверху.

## Форма
- Радиус: 12px для кнопок, 20px для карточек и фото.
- Без теней: глубину задают подложки и границы.

## Компоненты
- **Кнопка primary**: фон `--primary`, высота 50px, 600; hover — светлее на 8%.
- **Кнопка ghost**: прозрачная, граница `--line`; hover — граница `--muted`.
- **Строка цены**: название слева, «от N ₽» справа цветом `--primary`, разделитель снизу.
- **Карточка**: `--surface`, граница `--line`, радиус 20px, padding 24px.
- **Мобильная панель**: закреплена внизу, «Позвонить» (primary) + «Маршрут» (ghost).

## Фото и иконки
- Фото клиента крупно, радиус 20px, без фильтров.
- Иконки: один линейный набор (Lucide), без эмодзи.
- Избегаем градиентов, стекла и градиентного текста.
