# Сайты-фриланс — план

Сайты для автосервисов и шиномонтажек (РФ). Делаем один сайт-эталон для реального клиента, потом продаём его другим компаниям: меняем данные и слегка подстраиваем стиль.

## Продукт
- Одностраничный лендинг. Если клиенту нужно больше, усложняем под него отдельно.
- Один шаблон (`_template/`). На каждого клиента меняются только данные (`clients/<имя>/client.json`) и тема (цвета/шрифт).
- Статика с заделом под админку: позже можно подключить CMS/редактор цен, если клиент возьмёт обслуживание.

## Блоки лендинга (каждый включается/выключается в конфиге)
1. Шапка: логотип, меню, телефон
2. Первый экран: «<услуга> в <район>», кнопки «Позвонить» и «Записаться», факты (рейтинг, стаж, посты)
3. Услуги и цены «от»
4. Преимущества
5. Фото работ и боксов
6. Отзывы
7. Часы работы, адрес, Яндекс.Карта, «Построить маршрут»
8. Футер

- **Мобильная версия в приоритете**: внизу закреплены «Позвонить» и «Маршрут». Десктоп тоже должен выглядеть хорошо.
- **Кнопка «Записаться»** только демонстрационная, заявку никуда не отправляет. Клиенту говорим, что можно подключить заявки в Telegram.

## Данные клиента
- Источник: ссылка на 2ГИС (позже и другие сайты).
- Сбор: агенты Haiku (`light-agents:scout`) снимают название, адрес, телефон, часы, услуги, цены, рейтинг, фото и ссылки.
- **Проверка**: отдельный агент сверяет каждое поле с исходной страницей. Неподтверждённые поля помечаются «не подтверждено» и не попадают на сайт, пока владелец проекта их не утвердит.
- Результат: `clients/<имя>/client.json` + `clients/<имя>/verify-report.md`.

## Фото
- Свои фото клиента из 2ГИС/Яндекса там, где они есть.
- Сток только для фона и иконок. Чужие машины не выдаём за работы клиента.

## Отзывы
- Виджет Яндекса/2ГИС ставим, только если он умеет сортировать (сначала положительные). Это нужно проверить.
- Иначе: блок «★ рейтинг · N отзывов» со ссылкой + 3–5 лучших отзывов, отобранных вручную, со ссылкой на оригинал.

## Стиль
- База: **B · Асфальт**, нейтральный тёмный, не спорит с фото. Подробно в `DESIGN.md`.
- Под каждого клиента меняем цвета/шрифт по его желанию.
- Превью стилей: `_docs/styles-preview.html`.

## Техника и хостинг
- Статический сайт (Astro или чистый HTML, решаем на этапе шаблона), git.
- Демо-эталон: GitHub Pages.
- Клиентам: Timeweb, домен покупается на имя клиента.
- Яндекс.Метрика (клики по «Позвонить» и «Маршрут») подключается после продажи на аккаунт клиента, если это несложно. В демо её нет.

## Деньги
- Разовая оплата + абонентка (хостинг, правки, отчёт), если клиент хочет.

## Регион
- РФ, русский язык, Яндекс.Карты, 2ГИС.

## Структура папок
```
Сайты-фриланс\
  _template\        эталонный шаблон (git), по нему строим всех клиентов
  _docs\            PLAN.md, DESIGN.md, превью стилей
  clients\<имя>\    client.json, фото, отчёт проверки, сборка сайта
```

## Следующие шаги
1. Получить ссылку на 2ГИС клиента-эталона.
2. Собрать данные агентами и проверить их агентом-проверяльщиком.
3. Собрать шаблон в стиле B и наполнить данными клиента.
4. Выложить демо на GitHub Pages.
