# Как выложить сайты на GitHub Pages

Итог: все сайты по адресам вида `https://<логин>.github.io/<репозиторий>/<клиент>/`,
например `https://den9mai.github.io/sites-demo/damir-avto/`.

Идея: в репозиторий кладём шаблон, `client.json` клиентов и готовые сайты в папке `docs/`.
GitHub Pages показывает папку `docs/`. Сырые данные 2ГИС (`facts-2gis.json`, `photos-2gis/`)
в репозиторий не попадают: они нужны только для сборки.

## 1. Собрать сайты в папку docs (каждый раз после правок)
Открыть терминал в папке `Сайты-фриланс` и выполнить:
```
node _template/publish.mjs
```
Скрипт пересоберёт всех клиентов и сложит их в `docs/<клиент>/`, а также создаст `docs/index.html` со списком сайтов.

## 2. Создать репозиторий на GitHub (один раз)
1. Зайти на https://github.com/new (войти в свой аккаунт).
2. Repository name: `sites-demo`.
3. Видимость **Public** (на бесплатном аккаунте Pages работает только для публичных репозиториев).
4. Галочки README, .gitignore и license НЕ ставить. Нажать **Create repository**.
5. Скопировать адрес вида `https://github.com/<логин>/sites-demo.git`.

## 3. Отправить файлы (первый раз)
В терминале в папке `Сайты-фриланс`:
```
git init -b main
git add .
git commit -m "Сайты автосервисов: шаблон и демо"
git remote add origin https://github.com/<логин>/sites-demo.git
git push -u origin main
```
При первом `git push` Windows откроет окно входа в GitHub: войти через браузер.

## 4. Включить GitHub Pages (один раз)
1. В репозитории: **Settings → Pages**.
2. Source: **Deploy from a branch**.
3. Branch: **main**, папка **/docs**. Нажать **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<логин>.github.io/sites-demo/`.
   Готовность видно во вкладке **Actions** (зелёная галочка).

## 5. Обновление после правок
```
node _template/publish.mjs
git add .
git commit -m "Обновление сайтов"
git push
```
Через минуту изменения будут на сайте.

## Важно
- Репозиторий публичный, поэтому всё содержимое видят все. Не храните в нём пароли и чужие личные данные.
- На демо-сайтах реальные телефоны и названия компаний. Перед показом клиенту это нормально, но если клиент откажется, удалите его папку из `clients/` и `docs/`, затем снова выполните шаг 5.
