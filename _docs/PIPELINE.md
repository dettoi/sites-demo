# Конвейер: ссылка 2ГИС → готовый сайт

Эталон: `clients/damir-avto/`. Все новые клиенты собираются по нему.

## Шаги на одного клиента

| # | Кто | Что делает | Результат |
|---|---|---|---|
| 1 | Скрипт | `node _template/fetch-2gis.mjs <ссылка> <slug>` | `facts-2gis.json`, `photos-2gis/` |
| 2 | Агент-сборщик (Sonnet) | По фактам и фото пишет `client.json`, выбирает фото, цвет и шрифт, собирает сайт | `client.json`, `site/` |
| 3 | Агент-проверяльщик (Haiku) | Сверяет каждое утверждение в `client.json` с `facts-2gis.json` | `verify-report.md` |
| 4 | Claude | Исправляет то, что нашёл проверяльщик, смотрит сайт в браузере на 375 и 1440 px | готово к показу |

Шаг 1 для всех клиентов запускается сразу, шаги 2–3 идут параллельно по клиентам.
Одновременно работают не больше 2 агентов Sonnet, так что 5 клиентов собираются в 3 волны.

## Правила для агента-сборщика

**Факты только из `facts-2gis.json`.** Телефон, адрес, часы, цены, рейтинг, награды, услуги и тексты отзывов не придумываются и не «улучшаются». Если факта нет, блок или поле убирается.

**Тексты.** Заголовок первого экрана: «<Главная услуга> в <район>». Лид — 1–2 предложения из реальных услуг и атрибутов. Преимущества — только то, что подтверждено атрибутами, фото или отзывами (Wi-Fi, детская комната, работа без выходных, фото/видео ремонта). Пишем просто, без «высококвалифицированных специалистов».

**Услуги.** Сначала 8 главных услуг, у первых трёх описание из атрибутов 2ГИС. Цены пишем «от N ₽», цены ≤ 100 ₽ — «уточняйте». Если цен нет совсем, во всех строках ставим «по осмотру».

**Отзывы.** 4 положительных (5★) с самым содержательным текстом. Текст дословный, можно сократить многоточием, но не переписывать. Без дат.

**Фото.** Посмотреть все фото (Read). Для первого экрана — фасад с вывеской или лучший кадр бокса. В галерею 6–9 фото, сначала работа и боксы, потом зона ожидания. Фото посетителей (`user-*`) — только если своих меньше 4. Фото без отношения к сервису (размытые, чеки, документы) не берём.

**Оформление под клиента.**
- `theme.primary` — цвет бренда по вывеске или логотипу на фото. На фоне `#0f1214` он должен хорошо читаться, белый текст на нём — контраст не ниже 4.5:1 (если ниже, `onPrimary: "#0f1214"`).
- `theme.fonts.head` — один из вариантов ниже, под характер места:

| Вариант | head | Когда |
|---|---|---|
| A · Технический (по умолчанию) | `{"family":"Unbounded","weights":"500;700","weight":700,"tracking":"-0.01em"}` | универсальный СТО, диагностика, ремонт |
| B · Чистый | `{"family":"Onest","weights":"400;500;700;800","weight":800,"tracking":"-0.03em"}` | премиальный сервис, детейлинг, аккуратный интерьер |
| C · Гаражный | `{"family":"Russo One","weights":"","weight":400,"tracking":"0"}` | шиномонтаж, грузовые, кузовной ремонт |
| D · Динамичный | `{"family":"Exo 2","weights":"500;700;800","weight":800,"tracking":"-0.01em"}` | тюнинг, спорт, мото |

Текстовый шрифт всегда Manrope (`body` не задаём).

**Сборка.** `node _template/build.mjs <slug>` должна пройти без ошибок. Шаблон (`_template/`) не трогать. Если чего-то не хватает в шаблоне, написать об этом в отчёте.

## Правила для агента-проверяльщика
Для каждого поля `client.json` (контакты, координаты, часы, цены, рейтинг, награды, факты первого экрана, преимущества, цитаты отзывов) найти подтверждение в `facts-2gis.json`. Вердикт по каждому: ✅ / ❌ (с правильным значением) / ❓. Отчёт в `clients/<slug>/verify-report.md`.
